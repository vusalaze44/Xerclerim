# Mərhələlər

1. **İlkin skelet (bu dəyişiklik):** lokal gəlir/xərc qeydiyyatı, cari ay xülasəsi, qəpik dəqiqliyi, arxitektura və qapalı Firebase qaydaları.
2. **Hesab və sinxronizasiya:** Firebase layihəsi, Auth, istifadəçi üzrə şifrəli lokal baza, cihaz dəyişmə ssenariləri, idempotent iki istiqamətli sync və Firestore qaydaları.
3. **Öhdəliklər:** kredit kalkulyatoru, real ödəniş cədvəli və xatırlatmalar; dost sorğusu, qarşılıqlı təsdiq, hissə-hissə qaytarma və audit.
4. **Büdcə və proqnoz:** kateqoriya limitləri, ay sonu ssenariləri, “Alım, yoxsa almayım?” müqayisəsi.
5. **AI və ortaq xərclər:** hesablanmış faktların izahı, istifadəçi razılığı və məxfilik nəzarəti; ailə və qrup xərcləri ayrıca mərhələdir.

Buraxılışdan əvvəl Android/iOS cihaz testləri, məlumat miqrasiyası, təhlükəsizlik qaydaları və tətbiq mağazası konfiqurasiyası tamamlanmalıdır.
